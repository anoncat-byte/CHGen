## Tailwind CSS

In Windows PowerShell, install dependencies with `npm.cmd install`, then compile the Tailwind stylesheet with `npm.cmd run build:css`.
Use `npm.cmd run watch:css` while editing HTML or JavaScript to rebuild on changes.
